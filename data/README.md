# Disponibilidade dos dados

Não são distribuídos neste repositório:

- código-fonte institucional do SARSB;
- transcrições integrais dos grupos focais;
- comentários de revisão que possam identificar participantes;
- credenciais, configurações privadas ou artefatos operacionais da ANA.

O repositório fornece métricas agregadas, protocolo, codebook conceitual e estrutura de rastreabilidade. Solicitações de acesso a dados restritos devem seguir as autorizações institucionais e éticas aplicáveis.
